# 🌧️ Rainfall & Weather Analysis Dashboard using Power BI

## 📌 Project Overview
The Rainfall & Weather Analysis Dashboard is a data visualization project developed using Microsoft Power BI. It provides interactive insights into rainfall patterns, weather conditions, and related trends through visual representations.

This project helps users analyze weather data, identify patterns, and understand rainfall variations.

## 🎯 Objectives
- Analyze rainfall and weather data.
- Visualize rainfall trends using interactive charts.
- Identify patterns and variations in weather conditions.
- Create an interactive and user-friendly dashboard.
- Support data-driven decision-making.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Cleaning and Transformation

## 📊 Dashboard Features
- Rainfall Analysis
- Weather Trend Analysis
- Interactive Charts and Graphs
- KPI Cards
- Data Filtering and Slicers
- Comparative Weather Analysis

## 🚀 How to Run the Project
1. Download the `Rain_Analysis.pbix` file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open Power BI Desktop.
4. Open the downloaded `.pbix` file.
5. Explore the interactive dashboard.
